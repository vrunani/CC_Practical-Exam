🖥️ Virtualization
What is virtualization?▼
Virtualization is the process of creating a software-based (virtual) representation of something — such as servers, storage, networks, or operating systems — rather than a physical one.

A hypervisor (VMM – Virtual Machine Monitor) sits between hardware and the OS, allowing multiple VMs to run on one physical machine.

🎯 Key benefit: Better resource utilization, isolation, and cost savings by running multiple OS instances on one machine.
Is JVM a virtual machine? Is Java platform independent or dependent?▼
JVM (Java Virtual Machine) is a process virtual machine (not a system VM). It executes Java bytecode rather than virtualizing an entire OS or hardware.

Java is platform independent at the source level — "Write Once, Run Anywhere." Java code compiles to bytecode (.class files), which any JVM can run. However, the JVM itself IS platform dependent — a different JVM is installed for Windows, Linux, Mac, etc.

💡 Java code = platform independent | JVM = platform dependent

What is KVM? Draw KVM Architecture.▼
KVM (Kernel-based Virtual Machine) is a Type 1 hypervisor built into the Linux kernel. It converts Linux into a bare-metal hypervisor.

Architecture:
Hardware (CPU with VT-x/AMD-V support)
↓
Linux Kernel + KVM Module (/dev/kvm)
↓
QEMU (provides device emulation)
↓
Guest VMs (each with virtual CPU, RAM, storage)
KVM uses QEMU for I/O emulation and libvirt as the management layer.
What is LibVirt? What is QEMU?▼
LibVirt is an open-source API and management toolkit for managing platform virtualization. It provides a unified interface to manage KVM, QEMU, Xen, VirtualBox, etc. Key commands: virsh list, virsh start, virsh shutdown, virsh define.

QEMU (Quick EMUlator) is an open-source machine emulator and virtualizer. When used with KVM, QEMU handles I/O device emulation while KVM handles CPU and memory virtualization for near-native performance.
What is CloudSim?▼
CloudSim is a simulation toolkit for modeling and simulating cloud computing environments and services. It allows researchers to evaluate algorithms and policies for cloud resource management without needing real infrastructure.

It simulates: Datacenters, VMs, cloudlets (tasks), brokers, and resource scheduling.
📦 Used in research to test scheduling algorithms, load balancing, and resource allocation policies.

Shortcomings of PaaS▼
1. Vendor lock-in – difficult to migrate apps to another provider
2. Limited control – can't control the underlying infrastructure
3. Runtime limitations – may not support all languages/frameworks
4. Data security concerns – sensitive data lives on vendor's platform
5. Customization limits – less flexibility than IaaS
Essential characteristics of cloud computing▼
According to NIST, cloud computing has 5 essential characteristics:

1. On-demand self-service – provision resources without human interaction
2. Broad network access – accessible over the network via standard mechanisms
3. Resource pooling – shared resources serve multiple consumers (multi-tenancy)
4. Rapid elasticity – scale up/down quickly based on demand
5. Measured service – pay-as-you-go, usage is metered and monitored

🔐 Security
Why is encryption needed in cloud?▼
Encryption converts data into unreadable ciphertext so only authorized parties with the decryption key can read it.

Why it's needed in cloud:
1. Data in transit – data traveling over networks can be intercepted (man-in-the-middle attacks)
2. Data at rest – files stored on cloud servers could be accessed by unauthorized parties or even cloud staff
3. Regulatory compliance – GDPR, HIPAA require data protection
4. Multi-tenancy risk – multiple users share infrastructure; encryption keeps data isolated
5. Breach protection – even if data is stolen, it's useless without the key

⚙️ Resource Optimization
What is resource optimization? Algorithms? Who decides?▼
Resource optimization in cloud means allocating computing resources (CPU, memory, storage, bandwidth) efficiently to maximize utilization while minimizing cost and energy consumption.

Common algorithms:
1. First Fit / Best Fit / Worst Fit – bin-packing style VM placement
2. Round Robin – distribute tasks evenly across VMs
3. Genetic Algorithm – evolutionary optimization for multi-objective scheduling
4. PSO (Particle Swarm Optimization) – nature-inspired optimization
5. Throttled / FCFS – simple cloud scheduler approaches

Who decides? The cloud resource manager / scheduler (automated) decides, based on policies set by the cloud administrator or SLA requirements.
📊 Big Data
What is Big Data? Value of a Petabyte? Explain Velocity.▼
Big Data refers to extremely large datasets characterized by the 5 V's: Volume, Velocity, Variety, Veracity, Value — too large to process with traditional tools.

Value of 1 Petabyte:
1 PB = 1,024 TB = 1,048,576 GB = 1,073,741,824 MB
Velocity – the speed at which data is generated and processed.
Example: Twitter generates ~500 million tweets/day. Stock market processes thousands of transactions per second. For big data systems, data must be ingested and analyzed in near real-time (stream processing via Apache Kafka, Spark Streaming).
What is multi-tenancy? What is isolation in cloud?▼
Multi-tenancy means multiple customers (tenants) share the same cloud infrastructure (hardware, servers, databases) but their data and processes are logically separated.

Example: Gmail serves millions of users on the same infrastructure; each user can't see another's emails.

Isolation ensures that each tenant's data, processes, and resources are kept completely separate from others — even though the underlying hardware is shared. Achieved through: Virtual machines, containers, namespaces, and encryption.
